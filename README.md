# Stored Research Inline ETA

A RimWorld 1.6 UI mod that appends an estimated completion time to the final research-progress line in the lower-left inspect pane. It accounts for active researchers, facilities, difficulty, faction tech level, multiple maps, and stored research points when **Stored Research** is active.

Stored Research is optional; without it, the mod uses vanilla research progress. Harmony is required.
